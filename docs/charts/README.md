# Charts

Data-visualization artifacts generated by the `/chart` skill (HAPImatic-dark ECharts theme).

Each chart is a pair named `<unix_ts>-<kebab-description>.{png,html}`:
- `.png`  — static render (shown inline in the HAPImatic chat thread)
- `.html` — the interactive ECharts chart (open in a browser for legend toggle / zoom / tooltips)

The unix-time prefix sorts charts chronologically; the description says what each one depicts.
This directory is git-tracked so charts sync to GitHub. Prune charts you no longer need manually.
